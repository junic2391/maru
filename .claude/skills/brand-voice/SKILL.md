# brand-voice

원본: `/Users/junic/Documents/workspace/projects/maru-journal/source/BrandGuide.md` **L228–439** (9장 톤앤보이스 · 10장 마이크로카피 사전). i18n 키가 필요하면 10장을 직접 읽어 정확한 키·문구를 그대로 쓴다 — 즉흥적으로 새 문구를 만들지 않는다.

## 톤 원칙 (9.1)

1. 존댓말이되 딱딱한 격식체는 피한다
2. "죄송합니다/오류/실패" 같은 사과·경고 어휘보다 **무슨 일이 있었고 다음에 뭘 하면 되는지**를 먼저 말한다
3. 기능 이름은 사용자 언어로 ("통역 자막", "STT/MT 파이프라인" 아님)
4. 한 화면에 감성적 문장은 하나까지
5. 사용자를 탓하지 않는다 ("잘못 입력하셨습니다" 금지)

## 안전 상황(신고·제재)은 톤이 다르다 (9.2)

편안함보다 명확함이 먼저다: 완곡어법 금지, 사과하지 않음, 제재 사유는 구체적으로 밝히지 않되 남은 시간·문의 경로는 명확히, 신고자에게 결과를 약속하지 않음("확인하고 조치할게요"까지만), 피신고자를 단정하지 않음("신고가 접수되어 이용이 제한됐어요").

## 대조 예시 (9.3)

| 상황 | 이렇게 | 이렇게 쓰지 않는다 |
|---|---|---|
| 연결 성공 | 연결됐어요 | 성공적으로 연결되었습니다 |
| 연결 실패 | 연결이 끊어졌어요. 다시 시도해 주세요 | 오류: 연결에 실패했습니다 |
| 권한 거부 | 카메라와 마이크를 허용해야 통화할 수 있어요 | 권한이 거부되었습니다 |
| 로딩 | 연결하고 있어요 | 처리 중... |

영문은 직역하지 않고 같은 태도를 자연스러운 영어로 다시 쓴다 (느낌표 없이, "Please" 남발 금지).

## 마이크로카피 사전 (10장) — i18n 키 존재 영역

`landing.*`, `auth.*` / `welcome.*`, `home.*` / `match.*`, `lobby.*`, `call.*`, `report.*` / `sanction.*`, `invite.*` / `guest.*`, `settings.*` / `delete.*`, `end.*` / `error.*` 네임스페이스가 이미 한/영 확정되어 있다(BrandGuide.md **L287–434**). 새 문구가 필요하면 이 사전에 먼저 없는지 확인하고, 없으면 9장 원칙에 맞춰 추가한 뒤 이 문서(원본)에도 반영한다.

**변수 표기**: `{duration}` 처럼 중괄호로 통일한다. 문장을 조각내어 이어붙이지 않는다 — 언어마다 어순이 다르다.
