## 사용 방법

1. 구현할 화면의 S번호를 확인
2. 위 표의 라인 근처(±30줄)를 `Design.md`에서 Read
3. 컬러·타이포·간격 값은 `design-tokens` 스킬을 함께 참고 (여기는 레이아웃·흐름만)
4. 문구는 `brand-voice` 스킬의 마이크로카피 사전을 그대로 쓴다 — 화면 구현 중 문구를 즉흥적으로 만들지 않는다
5. SSR/CSR 경계는 3.1 표의 "렌더링" 열을 따른다 (ADR-008)
