- **ADR-004가 `제안됨`이라 `.claude/defense-zones.json`이 아직 키워드 기반 잠정치다.** M1-04에서 상태 머신 파일 경로를 정할 때 실경로로 갱신하고 ADR-004를 `채택됨`으로 바꾼다.
