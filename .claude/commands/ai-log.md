`adr-format` 스킬의 PR 템플릿 형식을 사용한다. 현재 브랜치와 base(main) 사이의 `git diff`, `git log`를 근거로 아래를 채워 출력한다(파일로 저장하지 않고 그대로 답변에 출력 — 사용자가 PR 본문에 붙여넣는다):

```markdown
## AI 사용 기록
- 도구:
- 위임한 범위:
- 직접 작성한 범위:
- 거부한 제안과 이유:
```

**"위임한 범위"·"직접 작성한 범위"는 이 PR의 핵심 기능(브랜치명·태스크 ID가 가리키는 것)과 직접 관련된 커밋만 근거로 삼는다.** 같은 세션에서 곁들여 고친 스킬·가이드 문서·설정 같은 부수적인 커밋은 diff·log에 있어도 제외한다 — 그건 각 커밋 메시지로 이미 남아 있다(CLAUDE.md "커밋·브랜치" 참고).

"거부한 제안과 이유"는 `/Users/junic/Documents/workspace/projects/maru-journal/docs/ai-rejections.md`에 이번 작업 기간과 겹치면서 **이 PR의 핵심 기능과도 관련 있는** 항목이 있으면 요약해서 채운다. 기간만 겹치고 주제가 무관하면(예: 별개 조사 중 나온 거부) 포함하지 않는다. 없으면 빈 칸으로 두고 사용자에게 알린다 — 지어내지 않는다.
