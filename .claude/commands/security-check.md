---
description: security-checklist 스킬 기준으로 보안 항목 충족 여부를 점검한다
---

`security-checklist` 스킬을 로드한다. 그 안의 두 표 — "maru 특화 보안 결정"(ephemeral token, 데이터 최소화, TURN 릴레이, 연령 확인 한계, 신고·차단, 콘텐츠 모더레이션 한계, 링크 초대 악용 방지)과 "일반 프론트엔드 보안 체크리스트"(XSS, CSRF, CSP, 토큰 만료·재발급, Rate limit, 민감정보 로깅) — 각 항목에 대해:

1. 레포 안에서 관련 구현을 찾는다(API 라우트, 미들웨어, 토큰 발급 로직, 응답 헤더 설정, 신고·차단 핸들러 등)
2. 구현이 있으면 어느 파일에 있는지 근거와 함께 "충족"으로 표시
3. 구현이 없거나 부분적이면 "미충족"으로 표시하고 무엇이 빠졌는지 한 줄로 적는다
4. "일반 프론트엔드 보안 체크리스트" 표는 Concept.md에 대응 절이 없으므로, 원칙만 보고 충족으로 단정하지 않는다 — 실제 코드를 찾지 못하면 반드시 "미충족" 또는 "확인 불가"로 표시한다

결과를 두 표로 나눠 출력한다. 파일 생성이나 수정은 하지 않는다 — 점검만 한다.
