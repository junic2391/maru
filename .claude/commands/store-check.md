---
description: store-compliance 스킬 기준으로 스토어 심사 미충족 항목을 점검한다
---

`store-compliance` 스킬을 로드한다. 그 안의 스토어 심사 체크리스트(EULA 동의, 콘텐츠 필터링, 신고 수단, 차단, 신고 대응, 공개 연락처, 계정 삭제, 소셜 로그인, 연령 등급) 각 항목에 대해:

1. 레포 안에서 관련 구현을 찾는다(라우트, 컴포넌트, API 핸들러 등)
2. 구현이 있으면 어느 파일에 있는지 근거와 함께 "충족"으로 표시
3. 구현이 없거나 부분적이면 "미충족"으로 표시하고 무엇이 빠졌는지 한 줄로 적는다

결과를 표로 출력한다. 파일 생성이나 수정은 하지 않는다 — 점검만 한다.
